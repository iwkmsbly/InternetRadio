01 / What this does

One place to tune in.

Choose a saved station or paste a direct HLS address ending in .m3u8. Airwave uses the browser’s native HLS support when available, or hls.js in supported browsers.

02 / A note on streams

The broadcaster sets the rules.

Some streams require a token, cookies, or a broadcaster-specific player. If a station blocks cross-origin playback, this page cannot override that restriction. Try the same URL in a browser that supports HLS natively.
